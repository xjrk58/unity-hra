# Reference: ovládání

## Klávesnice a myš

| Akce | Ovládání |
|------|----------|
| Pohyb | `W` `A` `S` `D` |
| Sprint (dopředu) | `Shift` |
| Rozhlížení | myš |
| Skok | `Space` |
| Vyprdnout prdy (v cíli) | drž levé tlačítko myši |
| Prdnout po soupeři nebo příšeře pod zaměřovačem (2 prdy) | pravé tlačítko myši |
| Nová hra (po zápase) | `R` |
| Ukončení | `Esc` |

V menu se tlačítka mačkají myší; `Esc` vrací zpět, na první stránce hru
ukončí.

## Dotyková obrazovka

Hraje se na šířku.

| Akce | Ovládání |
|------|----------|
| Pohyb | palec kdekoli v levých 42 % obrazovky: objeví se pod ním páčka |
| Sprint | zatlač páčku až na okraj |
| Rozhlížení | táhni prstem kdekoli po zbytku obrazovky |
| Skok | tlačítko **SKOK** |
| Vyprdnout prdy | nic – stačí stát v cíli |
| Prdnutí (2 prdy) | tlačítko **PRD!**; rozsvítí se oranžově, když by prdnutí zasáhlo |
| Nová hra (po zápase) | klepnutí, jakmile je banner zobrazený 1,5 s |
| Ukončení | systémové tlačítko nebo gesto Zpět |

Každý ovládací prvek si drží prst, který na něm začal, dokud se ten prst
nezvedne, takže pohyb, rozhlížení a mačkání tlačítka fungují zároveň. Zdvih
páčky je 13 % výšky obrazovky a páčka následuje palec, který sklouzne za její
okraj. Tah přes celou výšku obrazovky otočí pohled o 115°.

Dotykové rozložení se používá na telefonech a tabletech a na počítači, když se
hra spustí s `-touchHud`.

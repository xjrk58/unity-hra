# Reference: controls

## Keyboard and mouse

| Action | Control |
|--------|---------|
| Move | `W` `A` `S` `D` |
| Sprint (forward) | `Shift` |
| Look | mouse |
| Jump | `Space` |
| Expel farts (in the goal) | hold the left mouse button |
| Blast the rival or the monster under the crosshair (2 farts) | right mouse button |
| New game (after the match) | `R` |
| Quit | `Esc` |

In the menu the mouse clicks buttons; `Esc` goes back, or quits from the first
page.

## Touch screen

The game is played in landscape.

| Action | Control |
|--------|---------|
| Move | a thumb anywhere in the left 42 % of the screen: a stick appears under it |
| Sprint | push the stick to its rim |
| Look | drag anywhere on the rest of the screen |
| Jump | the **SKOK** button |
| Expel farts | nothing – standing in the goal is enough |
| Blast (2 farts) | the **PRD!** button; it lights up orange when a blast would hit |
| New game (after the match) | tap, once the banner has been up for 1.5 s |
| Quit | the system Back button or gesture |

Each control keeps the finger that started on it until that finger lifts, so
moving, looking and pressing a button work together. The stick's travel is
13 % of the screen height and it follows a thumb that slides past its rim. A
full drag across the height of the screen turns the view 115°.

The touch layout is used on phones and tablets, and on a computer when the
game is started with `-touchHud`.

## Menu

| Button | Does |
|--------|------|
| **Hrát sám** | a solo match |
| **Hra pro dva: založit** | hosts a two-player match and shows the game code |
| **Hra pro dva: připojit se** | lists games found on the Wi-Fi and paired Bluetooth phones; number pad for the code |
| **Zpět** | back |

# Documentation / Dokumentace

- **English:** [docs/en](en/index.md)
- **Česky:** [docs/cs](cs/index.md)

Both sets have the same four parts, following [Diátaxis](https://diataxis.fr):
tutorials (learning by doing), how-to guides (getting a job done), reference
(facts to look up) and explanation (why things are the way they are).

Obě sady mají stejné čtyři části podle [Diátaxis](https://diataxis.fr):
tutoriály (učení praxí), návody (jak něco udělat), referenci (fakta k dohledání)
a vysvětlení (proč jsou věci tak, jak jsou).
